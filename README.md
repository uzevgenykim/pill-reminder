# Таблетки: напоминания о приёме лекарств (Android)

Kotlin + Jetpack Compose + Room. Минимальная версия Android: 8.0.

## Как получить APK (GitHub Actions)

1. Создайте репозиторий на github.com (New repository, можно Private).
2. Загрузите в него содержимое этой папки целиком (вместе с папкой `.github`).
3. Откройте вкладку **Actions** — сборка запустится сама (или Run workflow вручную).
4. Через 5–7 минут откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `Tabletki-APK`.
5. Распакуйте zip, перенесите `app-debug.apk` на телефон и установите (разрешите установку из неизвестных источников).

## Как работают напоминания

- В назначенное время приходит уведомление с кнопками «Принял» и «Отложить на 30 мин».
- Всего 4 показа: в назначенное время и ещё 3 повтора с шагом 30 минут.
- Если после последнего напоминания приём не отмечен в течение 30 минут, он становится «Пропущен» (красный на графике).
- Принятые приёмы на графике зелёные.
